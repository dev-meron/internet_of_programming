## Design notes

- Default theme: **dark** ("Midnight Clay" palette — deep warm espresso background, dusty rose accent)
- Light theme: "Bone & Clay" warm editorial palette (available via the toggle in the top-right)
- Typography: Inter (body/UI) + Fraunces serif (display headings, italic for last name)
- Designer touches: editorial section numbers (01/02/03/04), italic last name, vertical "Portfolio · 2026" side label, "currently" life strip, ornament dividers, marquee tech strip, cursor-follow accent dot, soft rose wash in hero
